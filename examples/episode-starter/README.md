# Episode starter example

Copy `templates/episode/` to `episodes/your-slug/` — not this folder directly.

This folder holds reference stubs:

- `shots.ts` / `style.ts` — prompt pattern
- `YOUTUBE.md` — packaging template

Full worked example (EP003 Baby Memory) lives in LouisKartavyi monorepo:
`DeepGlitchFiles/pipeline/episodes/003-baby-memory/` (not shipped — contains generated assets).
